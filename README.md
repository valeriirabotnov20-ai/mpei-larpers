# MPEI LARPERS · сайт CTF-команды

Статический многостраничный сайт команды **mpei_larpers** (НИУ МЭИ). Без сборки, без npm, без фреймворков: HTML + один CSS + один короткий скрипт. Готов к публикации на GitHub Pages как есть.

Дизайн и структура повторяют `teamspirit.gg`: белый вертикальный рельс с меню слева, чёрная сцена, гигантское слово за контентом, белые прямоугольные кнопки без скруглений, узкая колонка контента 448px, белая плашка футера на главной. Палитра строго монохромная, как на шаблоне: чёрный `#000`, белый `#fff`, полутона только через прозрачность белого: `rgba(255,255,255,.44)` для подписей и `.14` для линий. Красного и синего в системе нет.

## Страницы

| Файл | Что это |
|---|---|
| `index.html` | главная: только логотип команды (фон `hero.webp`) |
| `about.html` | о команде: чем занимаемся, направления, как попасть |
| `team.html` | состав: карточки игроков (клик по нику раскрывает карточку, как на teamspirit.gg) и открытые слоты по направлениям |
| `partners.html` | партнёры: белые квадраты с логотипами, как на teamspirit.gg (сейчас НИУ МЭИ, ведёт на mpei.ru) |
| `brand.html` | брендбук: логотип, палитра, шрифты, правила |
| `404.html` | страница ошибки |
| `css/style.css` | все стили, включая мобильную версию |
| `js/main.js` | мобильное меню (бургер, крестик, Escape) и карточки игроков |
| `js/i18n.js` | переключение языка RU/EN: словарь переводов и квадратики в шапке |
| `assets/` | логотип команды (чёрный и белый), логотип МЭИ в градациях серого, hero-графика, иконки, соцпревью, фото игроков в `assets/players/` |
| `build/` | скрипты и шаблоны, которыми собрана графика (в деплое не нужны) |

## Как посмотреть локально

```bash
cd mpei-larpers
python -m http.server 8080
# открыть http://localhost:8080
```

## Что заменить своим

Все места помечены в HTML комментарием `ЗАМЕНИ`:

1. **Ссылки**: в кнопках шапки (`t.me/...`, `ctftime.org`) и в карточках состава. Сейчас Telegram ведёт на указанные в макете аккаунты.
2. **Состав**: карточки в `team.html`, блок `.team-page__list`. У каждой карточки:
   * `team-player__photo` — большое фото (на широком экране оно выезжает справа), файл `assets/players/<ник>.jpg`;
   * `team-player__nick` — ник, он же имя файла с фото;
   * `team-player__name` — имя и фамилия;
   * внутри `team-player__body` три поля: Роль, Биография, Социальные сети.
   Клик по нику раскрывает карточку, повторный клик, ссылка «Состав» или Escape закрывают. Ссылка вида `team.html#lavbarr` открывает карточку сразу.
   Открытые слоты ниже: `<div class="roster__item roster__item--open"><b>Web</b><span>Слот открыт · …</span></div>`.
3. **Партнёры**: плитки в `partners.html`.
4. **Карточки на главной**: `index.html`, блок `index-page__cards` (роль, ник, имя; второй блок про набор).
5. **Тексты**: заголовок на главной, абзацы в `about.html`, `title` и `og:*` в каждой странице.

## Двуязычность (RU/EN)

Перевод живёт в `js/i18n.js`: словарь `DICT` (ru/en) и ключи `data-i18n` в разметке. Квадратики RU/EN в шапке меняют язык, выбор запоминается в localStorage, ссылка `?lang=en` открывает страницу сразу на английском.

Как добавить текст: в разметке ставим `data-i18n="ключ"`, в словаре добавляем `'ключ': 'текст'` в оба языка. Для атрибутов (title, aria-label) есть `data-i18n-attr="aria-label:ключ"`. Если в переводе нужен HTML (`<b>`, `<a>`), он подставляется как разметка, для чистого текста добавьте `data-i18n-raw`.

## Публикация на GitHub Pages

```bash
cd mpei-larpers
git remote add origin https://github.com/<твой-ник>/mpei-larpers.git
git push -u origin main
```

Дальше: **Settings → Pages → Source: Deploy from a branch → Branch: `main`, папка `/ (root)` → Save**. В Settings → Pages укажи custom domain `mpei-larpers.ru`. Перед настройкой DNS сначала добавь домен в GitHub, чтобы закрепить его за аккаунтом и избежать риска перехвата поддомена. У корневого домена (`@`) у регистратора создай четыре A-записи GitHub Pages:

```text
185.199.108.153
185.199.109.153
185.199.110.153
185.199.111.153
```

Рекомендуется также настроить `www` как CNAME на `<имя-пользователя>.github.io` (без имени репозитория). После обновления DNS включи Enforce HTTPS в Settings → Pages. Обновление DNS может занять до 24 часов. Подробности — в [документации GitHub Pages о пользовательском домене](https://docs.github.com/en/pages/configuring-a-custom-domain-for-your-github-pages-site/managing-a-custom-domain-for-your-github-pages-site).

## Пересборка графики

Hero-картинки, полосы внутренних страниц, плитки блога и соцпревью рисуются headless Chrome из HTML-шаблонов в `build/`. Всё в монохромной палитре:

```bash
cd mpei-larpers
python build/make_mono.py            # только шаблоны
python build/make_mono.py --render   # шаблоны + рендер в assets/
```

`build/make_mono.py` держит палитру в одном месте (константы `BG`, `INK`, `DIM`), пишет `hero.html`, `hero-mobile.html`, `band-*.html`, `tile-*.html`, `og.html` и сам вызывает Chrome и Pillow. `logo-cut.png` для фигуры на главной это копия `assets/logo-light.png`.

Требуется установленный Chrome. Шаблоны берут шрифт Oswald из Google Fonts, так что нужен интернет.
